# Argent AI

Argent AI is a modular local AI vision server designed for Home Assistant.

## Features

- Local image analysis
- FastAPI REST API
- Ollama integration
- Ring camera support
- Home Assistant integration
- Pluggable vision backends
- Local-first architecture

## Planned Vision Backends

- Ollama
- Apple Vision/Core ML
- Frigate
- YOLO
- OpenCV

## Future Features

- Event memory
- Multi-camera reasoning
- Natural-language notifications
- Known-person recognition
- Package detection
